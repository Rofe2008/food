# Elemes.id - Food Delivery Website UI

In proekt yak namunai dastras va jozibadori UI (User Interface) baroi vebsayti intikoli ghazo (Food Delivery) meboshad. Proekt ham baroi versiyai **Desktop** va ham baroi versiyai **Mobile** (Responsive) tarrohi va kor karda shudaast.

---

## 🚀 Hususiyatkhoi Asosi (Features)

* **Tarrohii Responsive:** Toza va khushnamo dar kompyuter va telefonkhoi mobil.
* **Kategoriya-kho (Categories):** Bakhshi intikhobi ghazokho bar ososi namud (Kupkeyk, Pitza, Kebab, Salmon va ghayra).
* **Ghazokhoi Mashhur (Trending Items):** Namoishi ghazokhoi purkharidtarin bo reyting (stars) va narkh.
* **Footer-i Mukammal:** Shomili malumoti aloqa, shabakahoi ijtimoi va obunashavi ba khabarnoma (Newsletter).

---

## 🛠️ Tekhnologiyakho (Technologies Used)

Dar in proekt tekhnologiyakho zerin istifoda shudaand:
* **HTML5** - Baroi strukturai sayt.
* **CSS3 / Tailwind CSS** - Baroi tarrohi va estotika (Styling).
* **JavaScript** - Baroi dinamika va kor kardani bakhshkho (masalan, karusel yoki menyu).
